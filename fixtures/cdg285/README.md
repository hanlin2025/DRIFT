# CDG-285 offline AIS rehearsal fixture

`fictional_ais_track.csv` is entirely fabricated for local development and rehearsal. The names and MMSIs (`990285001`, `990285002`) are fixture labels, not assertions that these identify assigned vessels. No IMO is assigned. Coordinates and timestamps are illustrative Singapore-area values, not observations from AISStream or any real vessel.

Both tracks use `source=SEEDED`; they must never be labelled, mixed with, or presented as authentic AIS captures. Their proximity does not represent a booking, voyage, transshipment, or cargo relationship. Some optional report fields are intentionally missing to exercise quality handling.
